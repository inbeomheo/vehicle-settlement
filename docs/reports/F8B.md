# F8B — 기사 입력 폼·증빙 접근성 및 오류 처리

2026-09-29, `f7b` 브랜치에서 F8B 지시를 수행했다. 시작 기준은 최신 main을 병합한 `4d829e4`다. AGENTS.md, DESIGN.md, F7B·F5·F6 보고서를 읽고 `npm run db:migrate`를 먼저 실행해 성공했다. 웹 3118, PostgreSQL 54348을 사용했다.

## 수정 내용

1. **IndexedDB 실패 복구**: 직렬 저장 체인의 끝은 실패를 처리한 Promise로 유지하고, 실제 작업 Promise는 저장·로그아웃 flush 호출자에게 반환한다. 한 번 실패해도 다음 자동저장·주기 저장·수동 재시도·서버 저장·제출이 실행된다. `휴대폰 저장 실패 — 다시 시도` 버튼은 현재 입력을 다시 저장한다. 오래된 저장 완료가 새 입력의 완료 표시를 덮지 않도록 확인하며, 서버 전송 중에는 이전 편집본의 주기 저장을 막는다. 조회 캐시 쓰기 실패는 정상 서버 조회 결과를 버리지 않는다.
2. **오류와 입력 연결**: 검증 오류와 보완 요청에 ID를 부여하고 실제 입력의 `aria-describedby`와 `aria-invalid`에 연결했다. 기존 설명은 보존한다. 비용 묶음의 요청은 그 안의 입력에 전달하고 증빙 오류·보완 요청은 파일 입력과 전표번호에도 연결한다. 오류 요약은 항목 이동 버튼을 제공한다. 저장·제출 실패 시 첫 오류 입력 또는 포커스 가능한 요약으로 이동한다. 접힌 회차 열기·빨간 테두리는 유지한다.
3. **비동기 재진입 방지**: React가 disabled 상태를 반영하기 전에도 ref 잠금으로 중복 실행을 차단한다. 이전 운행 복사, 서버 저장·제출, 대리 입력 내용 확인, 최신 값 조회, 전송 재시도, 대기 첨부 제거, 취소·폐기를 점검했다. 기사 홈의 복사·재전송·더 보기와 증빙 준비·삭제에도 적용했다. 이동 성공 후에는 복사 버튼을 다시 활성화하지 않으며, 실패 시 다시 시도할 수 있다.
4. **인라인 확인 포커스**: 운행 취소·승인 운행 수정·기기 초안 폐기는 열릴 때 첫 버튼에 포커스하고, 취소 버튼 또는 Escape로 닫으면 원래 버튼으로 돌아간다. 승인 수정 확인 후에는 사용일 입력으로 이동한다.
5. **계약 조회 안내**: 계약·단가·예상 금액·조회 실패 영역에 `aria-live="polite"`, `aria-atomic="true"`를 적용했다. 금액 변경과 조회 실패를 같은 영역에서 알린다.
6. **사진 선택 포커스**: sr-only 파일 입력에 키보드 포커스가 오면 보이는 카메라·파일 선택 레이블에 2px 외곽선을 표시한다.
7. **대비·한국어 오류**: 기사 홈 운행번호와 폼·읽기 전용·증빙·내 정산의 보조 텍스트를 slate-600으로 조정했다. 브라우저·게이트웨이의 영어 네트워크 오류는 한국어 안내로 바꾸며 기존 한국어 업무 오류는 유지한다. 원본 오류 진단 문자열을 입력 화면에 노출하지 않는다.

## 판단과 범위

- 공용 `src/components/ui/` Modal은 작업 시점에 없었다. 기존 확인 UI는 인라인으로 유지하고 폼 전용 포커스 훅을 공유했다. 배경을 차단하는 모달이나 포커스 트랩은 추가하지 않았다.
- 자동저장 실패는 입력 중 포커스를 빼앗지 않고 재시도 버튼으로 알린다. 명시적인 저장·제출·복사 실패는 오류 요약에 포커스한다. 저장 장치가 계속 실패할 때 서버에 저장됐다고 표시하거나 기기 대기열을 건너뛰지 않는다.
- 오류 이동의 부드러운 스크롤이 빠른 키보드 이동과 충돌하는 재현을 확인해 즉시 스크롤로 바꿨다. 오류 입력의 가시성과 포커스를 함께 보장하기 위한 결정이다.
- 계약 안내는 기존 저장 상태의 `role="status"`와 구분되는 polite live region으로 구현했다. UI 안내만 변경하며 수량·금액·권한·상태의 최종 서버 판단은 유지한다.
- `error-message.ts`, `use-action-lock.ts`는 기사 화면과 공용 입력 폼에서만 사용하는 작은 클라이언트 유틸리티다. 공용 Field·Section·증빙 변경은 담당자 대리 입력에도 적용되므로 기존 전체 회귀를 함께 검증한다.
- F8a 소유인 `src/components/manager/**`, `src/app/m/statements`, `src/app/m/import`는 수정하지 않았다. 서버 서비스·DB 스키마·마이그레이션·패키지·lockfile·인증·권한도 변경하지 않았다.
