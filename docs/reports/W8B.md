## 데이터·호환성 결정

- 새 확정 스냅샷에는 기존 구현부터 `charge_type`이 포함되어 있었다. 타입을 optional로 보완하여 과거 필드 없는 스냅샷은 `—`로 표시한다. 기존 확정 스냅샷·합계·비용 금액은 변경하지 않는다. 마이그레이션 불필요.
- Excel/PDF 비용 종류는 마지막 열에 추가해 기존 수량 I열·공급가 K열·세액 L열을 유지한다. PDF 14열 폭을 가로 A4 본문 폭 안에 맞췄다.
- 가져오기 옵션은 화면에서 기본 true로 명시 전송한다. 기존 API 호출의 옵션 생략은 false로 유지한다. 과거 옵션 없는 저장 미리보기는 false로 복원한다. 파일의 명시적 0원은 그대로 CONFIRMED, 계약이 없는 빈 단가는 PENDING이다. 등록 상태는 기존 DRAFT/PROXY이고 자동 승인하지 않는다.
- 미확정 미리보기 삭제의 오래됨 기준은 마지막 수정 후 7일이다. 본인 PREVIEW만 잠금·검증 후 삭제하며 COMMITTED/FAILED/다른 사용자 작업은 보존한다. 원본 파일도 정리하고 감사 이력을 남긴다.
- 지급 요약의 `count`/`amount`를 추가하고 기존 `unpaid_count`/`unpaid_amount` 의미는 보존한다.
- 감사로그의 기존 역할별 접근 범위는 넓히지 않았다. 명세번호 검색은 해당 명세 이력에 접근할 수 있는 관리자에게 적용된다.

## 검증

- 전용 embedded PostgreSQL 54339, 개발/E2E 포트 3109. `.env`는 미추적.
- `npm run typecheck`, `npm run lint`, `npm run format:check`: 통과.
- `npm test`: 31개 파일, 190개 통과(실제 PostgreSQL 통합 테스트 포함).
- E2E: 담당자·정산·가져오기 신규 9개 및 관리자 신규 3개, 총 12개 모두 360/390/1440px에서 통과.
- ego-browser 실제 360px 사용대장·검수 상세: 가로 넘침 없음, 보이는 입력 16px 이상. Playwright에서는 1440px의 지급상태 열 우측 끝도 화면 안에 있는지 검증.
- E2E 전용 DB 실행 전후 개발 DB의 사용·명세·지급·증빙·감사·가져오기 건수 동일.
- PDF 비용 종류 전부 포함한 두 페이지를 렌더링하고 텍스트·마지막 열 잘림 여부를 확인했다. 로컬 산출물 `.data/w8b-qa/`는 커밋 제외.
- `npm run build`: 통과. 마지막 검증에서 `npm run typecheck && npm run lint && npm test && npm run build`를 순서대로 실행해 모두 통과했다.

## 기존 E2E와 새 화면 흐름

전체 기존+신규 E2E 첫 실행은 21개 통과, 3개 실패였다. 세 실패 모두 요구된 새 UX를 기존 시나리오가 수행하지 않아 발생했다.

- `tests/e2e/full-flow.spec.ts`, `tests/e2e/W4-settlement.spec.ts`: 기존 `명세 확정` 클릭 다음에 새 `확정` 재확인 클릭이 필요하다.
- `tests/e2e/W3-review.spec.ts`: 360px 전환 후 사용대장 링크 전에 새 `메뉴` 버튼 클릭이 필요하다.

이 세 파일은 지정된 `tests/*/W8b-*` 소유 범위 밖이므로 변경하지 않고, 각각 1줄씩 추가하는 수정안을 `.data/W8b-existing-e2e.patch`에 준비했다. 범위 예외 여부 확인 중이다. 새 W8b 회귀 테스트는 재확인 전 DRAFT 유지와 모바일 메뉴 열기까지 검증한다.


수정안 검증은 원본을 건드리지 않고 동일 디렉터리에 `W8b-verify-*` 임시 복사본을 만들어 수행했다. 위 세 줄만 반영한 기존 3개 파일의 **6개 시나리오 전부 통과**(기사→보완→검수→정산→출력→지급→지급 취소 포함). 검증 후 복사본은 삭제했다. 수정안을 원본에 적용하기 전까지 **원래 전체 E2E는 3개 실패 상태**이며, 전체 통과로 보고하지 않는다.

정확한 원본 테스트 수정안(범위 예외 확인 전 미적용):

```diff
# tests/e2e/full-flow.spec.ts 및 tests/e2e/W4-settlement.spec.ts
   await page.getByRole('button', { name: '명세 확정', exact: true }).click();
+  await page.getByRole('button', { name: '확정', exact: true }).click();

# tests/e2e/W3-review.spec.ts
   await page.setViewportSize({ width: 360, height: 800 });
+  await page.getByRole('button', { name: '메뉴', exact: true }).click();
```

## 남은 문제
