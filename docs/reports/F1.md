## 결정과 호환성

- 이전 해시 저장본은 동일 파일 SHA-256·시트·헤더·매핑·원본 행 번호와 실제 연결된 사용 건을 함께 조회해 중복을 막는다. 기존 확정·지급 내역이나 과거 해시를 재작성하지 않는다. 작업별로 원본 미리보기를 한 번만 읽어 반복 전송을 피한다. 새 해시는 계속 원본 행 값만 사용한다.
- 확정 API의 필수 토큰 계약을 `docs/API.md`에 기록하고 모든 기존 확정 호출 테스트·데모 시드를 갱신했다. `version` 충돌은 기존 `VERSION_CONFLICT`, 확정 불가 사유는 기존 `CONFIRM_BLOCKED`를 유지한다. 토큰은 정상 확정 가능한 최신 항목에 대해 비교한다.
- 토큰은 확인 내용의 변경 감지용이다. 금액·상태·권한의 최종 판단과 기존 잠금/부분 유니크 인덱스는 서버에 유지한다.
- 모바일 첫 진입은 모든 열을 선택해 핵심 영역과 펼침 영역으로 나누고, 데스크톱 첫 진입은 기존 축약 열로 시작한다. 이후 열 선택 상태는 표와 카드에 함께 적용한다.
- Poppler는 이 환경의 `/opt/homebrew/bin/pdftotext`를 사용한다. 새 npm 의존성은 추가하지 않았다. 테스트 환경에도 `pdftotext`가 필요하며, 미설치 시 검증을 건너뛰지 않고 실패한다.
- W8B 보고서에 남아 있던 기존 E2E 3개 UX 갱신은 현재 기준 커밋에 이미 반영되어 있어 추가 변경이 필요하지 않았다.
