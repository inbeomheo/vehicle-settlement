# 후속 기능

현재 완료 범위는 단일 회사의 사용 등록·검수·월 정산·전액 지급이다. 다음 목록은 후속 검토 항목이며 현재 지원 기능으로 약속하지 않는다.

| 우선 검토 | 기능 | 결정할 사항 |
| --- | --- | --- |
| 정산 확장 | 운송사 청구서 대조 | 업체별 엑셀 양식, 사용 건 매칭 키, 차액 허용 범위, 누락·추가 행 처리 |
| 정산 확장 | 부분지급·선지급·상계 | 잔액 원장, 배분 순서, 취소·조정 규칙, 회계 증빙 |
| 입력 편의 | 반복 운행·즐겨찾기 템플릿 | 기간·휴일·기사 변경과 중복 판정, 사용자 확인 절차 |
| 검수 편의 | 일괄 검수 | 현장 범위, 부분 실패, 선택 라인 보류, 승인자 추적 |
| 검수 편의 | 변경 전후 비교 | 제출 revision과 항목별 금액·증빙 차이 표시 |
| 정산 안내 | 이월 안내·늦은 승인 알림 | 마감 기준, 전월분 안내 대상, 읽음 이력 |
| 경영 분석 | 현장·차량·업체별 비용 분석 | 지급/청구 구분, 비교 기간, 부가세 기준, 다운로드 권한 |
| 협업 | 푸시·문자·메일 알림 | 수신 동의, 발송 비용, 재시도·중복 방지, 민감 정보 최소화 |
| 현장 운영 | 배차·운행 계획 | 기사 수락, 변경/취소, 실제 운행과 연결 |
| 현장 운영 | GPS·도착 확인 | 위치 수집 동의, 보존기간, 실내·통신 장애, 배터리 사용 |
| 증빙 | OCR·전표 자동 인식 | 신뢰도와 담당자 검토, 원본 유지, 모델 비용·보안 |
| 연동 | 회계·ERP·전자세금계산서·은행 API | 외부 식별자, 승인/지급 책임, 재전송·정합성, 감사 추적 |
| 계약 | 월대 일할·휴차공제·복잡 계약식 | 계약별 공식, 적용기간, 반올림·최소요금 우선순위 |
| 플랫폼 | 다회사·멀티테넌트 | 모든 접근/출력/백업 범위 분리, 이관·정산번호 정책 |
| 가져오기 | 대용량 비동기 작업·관리자 이력 공유 | 작업 큐·취소·재개, 권한 회수, 파일 보존, 프리셋 버전 |
| 운영 | 자동 백업 스케줄·암호화·원격 저장·PITR | 실명 책임자, 복구 목표, 키 관리, WAL 보관, 주기적 검증 |

추가 기능도 서버의 권한·금액·상태 판단, 원화 정수/Decimal 수량, 당시 스냅샷 보존, 실제 PostgreSQL 통합 테스트를 유지한다.
