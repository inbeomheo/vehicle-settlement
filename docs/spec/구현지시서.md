# 화물차 사용·청구·정산 앱 — 구현 지시서 (요약 원문)

> 사용자가 전달한 구현 지시서. 상세 설계는 `docs/DESIGN.md` 가 우선한다.

## 1. 목표
화물차 사용 내역을 기사와 담당자가 함께 기록·확인하고, 승인된 내역을 모아 청구서·정산서를 만드는 웹앱.
첫 버전 완료 흐름: 기사 또는 담당자 사용 내역 등록 → 증빙 제출 → 담당자 검수 → 거래처별 월 정산 → 엑셀·PDF 출력 → 지급 확인.
배차 없이 이미 사용한 차량 내역을 사후 등록하는 경로를 기본 제공.

## 2. 기본 방향
- 기사: 휴대폰 / 담당자: PC·휴대폰. 반응형 웹 + PWA. 같은 서버 원장 공유.
- 기본 업무: 외주 차량비 지급. 확장: 같은 사용 내역을 원청·고객에게 별도 단가로 청구.
- 거래처별 월 정산. 시간 기준 Asia/Seoul.
- 지원하지 않는 계약·지급방식을 다른 값으로 억지로 저장하지 않는다.

## 3. 참고 오픈소스
Trippr(MIT: 입력·단가·추가비·엑셀·PDF), Warp Tools(MIT: 기사 정산·지급 원장), Fleetbase(AGPL: 배차·기사앱), ERPNext(GPLv3: 거래처·청구·승인).
코드를 재사용하면 저장소·파일·라이선스·변경 내용을 `docs/THIRD_PARTY.md` 에 기록하고 고지 유지.

## 4. 사용자와 권한
기사 / 현장 담당자 / 정산 담당자 / 관리자. 서버에서 조회·수정·첨부 다운로드·엑셀·PDF에 동일 권한 적용. 작성자와 실제 기사 별도 기록.

## 5. 첫 버전 필수 기능
계정·권한(로그인, 초대, 역할, 현장 배정, 접근 회수) / 기준정보(현장, 거래처, 운송사, 기사, 차량, 차종·톤수) /
사용 등록(사후 등록, 기사 직접, 담당자 대리, 임시 저장) / 운행 실적 / 반복 입력(최근 현장·경로, 이전 운행 복사) /
단가·금액(과금단위, 적용 기간, 청구 수량, 단가, 추가 비용) / 증빙(첨부, 업로드 진행·실패·재시도) /
검수(제출, 승인, 보완 요청, 재제출, 변경 후 재승인) / 사용대장(검색·필터) / 월 정산(포함·보류, 합계, 확정·취소) /
출력(사용대장 엑셀, 정산명세 엑셀·PDF) / 지급 관리(예정일, 수동 지급 기록, 미지급 조회, 오입력 취소) /
기록 보존(변경자·시각·사유·이전 승인) / 운영 기본(입력 검증, 오류 표시, 백업·복구).
조건부: 엑셀 가져오기, 원청 청구·입금, 부분지급·선지급·공제, 월대·반일·시간·중량 과금, 지급 후 증감 조정.

## 6~7. 데이터 구조와 업무 규칙
docs/DESIGN.md §5, §6 참조 (① 사용 건·운행·과금 단위 분리 ~ ⑫ 권한 회수).

## 8~9. 화면·엑셀·출력
기사: 내 운행 / 운행 등록 / 내 정산. 담당자: 검수 대기, 사용대장, 상세, 월 정산, 명세 상세, 지급 관리, 기준정보, 사용자 관리.
합계가 현재 페이지 합계인지 전체 검색 결과 합계인지 명확히 표시.
엑셀 가져오기: 열 매핑, 미리보기, 검증, 행별 오류, 중복 의심 안내, 작업 이력. 가져온 자료는 검토 가능한 상태로 등록(자동 승인 금지).
출력 항목: 문서번호, 거래 상대방, 정산 기간, 실제 사용일, 현장, 차량·기사, 운반 내용, 과금단위·수량·단가, 기본운임·추가 비용, 세금, 합계, 비고. 화면·엑셀·PDF 일치.

## 12. 필수 검증 시나리오
| 시나리오 | 기대 결과 |
|---|---|
| 일대 30만 원에 실제 운행 5건 | 기본운임 30만 원 |
| 회당 10만 원에 청구 수량 5회 | 기본운임 50만 원 |
| 같은 날 같은 경로로 실제 두 번 운행 | 정상적인 운행 두 건 보존 |
| 같은 등록 요청을 두 번 전송 | 한 건만 생성 |
| 기사·차량·소속 업체 정보 변경 | 과거 기록의 당시 정보 유지 |
| 다음 달 계약 단가 변경 | 이전 승인·확정 금액 유지 |
| 승인 후 비용 수정 | 재승인 필요 |
| 담당자 두 명이 같은 항목을 동시 마감 | 유효 확정명세 중복 포함 방지 |
| 운행 저장 후 사진 업로드 실패 | 사진만 재전송, 운행 중복 없음 |
| 지급 완료를 잘못 입력해 취소 | 원기록·취소 이력 보존, 잔액 복구 |
| 전월 사용분을 다음 달 정산 | 실제 사용일과 정산 기간 각각 유지 |
| 다른 기사 자료·첨부·출력물 접근 | 서버에서 차단 |
| 엑셀·PDF 출력 | 확정명세의 내역·합계와 일치 |
| 단가 미확정 항목을 정산 확정 | 확정 차단 및 사유 표시 |
